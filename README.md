# ☕ Coffee Ordering Website

A modern and responsive Coffee Ordering Website built using **HTML5** and **CSS3**. This project showcases a visually appealing coffee shop landing page where users can browse coffee products, view special offers, and place orders through an intuitive user interface.

## 🚀 Features

* Responsive design for desktop and mobile devices
* Attractive coffee-themed user interface
* Navigation bar with smooth layout
* Coffee menu section
* Featured products and special offers
* Order section with call-to-action buttons
* Clean and organized HTML & CSS code
* Beginner-friendly project structure

## 🛠️ Technologies Used

* HTML5
* CSS3
